# Contributing to Web Scraping

Thank you for your interest in contributing to this project! 🎉

## How to Contribute

### Reporting Bugs

If you find a bug, please open an issue with:

- A clear description of the problem
- Steps to reproduce the issue
- Expected vs actual behavior
- Python version and OS information

### Suggesting Enhancements

We welcome suggestions for new web scraping examples! Please open an issue with:

- A clear description of the enhancement
- Why this would be useful
- Example use cases

### Pull Requests

1. **Fork the repository** and create your branch from `main`

   ```bash
   git checkout -b feature/your-feature-name
   ```

2. **Set up your development environment**

   ```bash
   python -m venv venv
   source venv/bin/activate  # On Windows: venv\Scripts\activate
   pip install -r requirements.txt
   ```

3. **Make your changes**

   - Write clear, commented code
   - Follow Python best practices (PEP 8)
   - Add examples or documentation if needed

4. **Test your changes**

   - Ensure your code runs without errors
   - Test with different scenarios

5. **Commit your changes**

   ```bash
   git commit -m "Add: brief description of your changes"
   ```

6. **Push to your fork**

   ```bash
   git push origin feature/your-feature-name
   ```

7. **Open a Pull Request**
   - Provide a clear description of your changes
   - Reference any related issues

## Code Style

- Follow [PEP 8](https://pep8.org/) style guide
- Use meaningful variable names
- Add comments for complex logic
- Keep functions focused and concise

## Adding New Scraping Examples

When adding new web scraping examples:

- Create a new notebook or Python file
- Include clear documentation and comments
- Add error handling where appropriate
- Respect website terms of service and robots.txt
- Consider rate limiting to be respectful to servers
- Update the README with your new example

## Code of Conduct

Please be respectful and inclusive in all interactions. See our [Code of Conduct](CODE_OF_CONDUCT.md) for details.

## Questions?

Feel free to open an issue for any questions or clarifications!
